# Quick Reference — Thumbnail Generation Cheat Sheet

---

## Workflow

```
1. Read content-brief.md + full-script.md + colors.ts
2. Identify the ONE most honest, compelling hook
3. Pick primary tactic + expression that matches the video's real tone
4. Write 3 manifest variants (different tactics, same honest hook angle)
5. Validate each manifest against the 7 mandatory criteria
6. User pastes nano_banana_prompt into Google Gemini with Nano Banana Pro
7. Upload creator reference face photo(s) alongside the prompt
8. Generate, review, iterate with conversational edits in Gemini
```

---

## YouTube Thumbnail Specs

| Spec | Value |
|------|-------|
| Resolution | 1920 x 1080 px (16:9) |
| File Size | < 2 MB |
| Format | PNG or JPG |
| Mobile Test Size | 150px width |
| Text Limit | 1-3 words, < 12 characters |

---

## Nano Banana Pro Prompt Structure

```
IDENTITY LOCK: Keep the person's facial features exactly the same as the reference image.
SUBJECT: [expression] + [position in frame] + [body visible] + [gaze]
OBJECT: [what it is] + [where in frame] + [visual details + colors]
BACKGROUND: [color/gradient with hex codes] + [atmosphere]
COMPOSITION: [layout] + [negative space location] + [3 elements only]
TEXT: "[EXACT WORDS]" in bold [color] sans-serif with [outline/shadow] at [position]
TECHNICAL: Professional YouTube thumbnail. 16:9 aspect ratio. 4K. High contrast. High saturation.
```

| Video Tone | Expression |
|---|---|
| Educational | Warm instructor — approachable smile, relaxed |
| Impressive result | Calm confidence — knowing smile, steady gaze |
| Surprising finding | Authentic curiosity — raised eyebrow, engaged eyes |
| Analysis/review | Thoughtful — hand near chin, focused |
| Genuine excitement | Real enthusiasm — smile reaching eyes, energized |
| Problem solved | Satisfied expert — slight smirk, confident posture |

---

## Honest Text Words

**Use:** TESTED, BUILT, COMPARED, FOUND, FIXED, FULL GUIDE, [number]X, [metric], NEW, HOW, WHY, DEEP DIVE, REAL, INSIDE, EVERY, ALL [n]

**Never:** BEST, INSANE, GAME CHANGER, SHOCKING, SECRET, HACK, DESTROYED, EXPOSED, DON'T MISS, YOU NEED THIS

## Mandatory Validation Gates

```
1. HONEST? → Video delivers what thumbnail promises?
2. CLEAR?  → Understandable in 1 sec at 150px?
3. SIMPLE? → Exactly 3 elements?
4. TEXT?   → <12 chars, not repeating title, readable?
5. FACE?   → 40%+ of frame, expression matches tone?
6. POP?    → High contrast, saturated, stands out?
7. SAFE?   → Nothing in bottom-right or edges?
```

All 7 must pass before generating.
